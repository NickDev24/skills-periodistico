# Aprendizaje de audiencia

Este skill no inventa preferencias de audiencia. Aprende de resultados observados.

## Registrar por pieza

- timestamp_publicacion
- tema
- zona
- formato
- plataforma
- titular
- gancho
- longitud
- voz
- score_editorial
- nivel_evidencia
- retencion_3s
- retencion_25
- retencion_50
- retencion_final
- CTR
- alcance
- compartidos
- guardados
- comentarios
- ocultamientos/denuncias
- tiempo_lectura cuando exista

## Comparaciones

Comparar primero piezas similares:
- mismo formato;
- plataforma;
- duración;
- tema;
- ventana horaria.

No concluir que un titular funciona mejor solo porque obtuvo más alcance si también tuvo una distribución distinta.

## Aprendizaje

Cada período producir:
1. patrones observados;
2. hipótesis;
3. evidencia;
4. cambio sugerido;
5. nivel de confianza.

Ejemplo:

"Los reels de servicio sobre tránsito publicados entre 07:00 y 09:00 tuvieron mayor retención mediana que otros reels de servicio durante las últimas 8 semanas."

Eso es una observación. No transformarla en regla universal sin suficientes casos.

## Feedback al score

Las métricas reales pueden recalibrar pesos, pero nunca eliminar:
- verificación;
- atribución;
- presunción de inocencia;
- protección de menores;
- abstención cuando corresponda.

El algoritmo optimiza distribución y atención dentro de límites editoriales, no la verdad.
